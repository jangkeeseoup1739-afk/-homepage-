# 내부 사진 넣는 곳

**이 폴더에 사진을 올리기만 하면 홈페이지 갤러리에 자동으로 나타납니다.**
코드는 건드리지 않으셔도 됩니다.

## 파일 이름

숫자로만 지어 주세요.

```
1.jpg
2.jpg
3.jpg
```

- 최대 **24장** (`1` ~ `24`)
- `jpg` · `jpeg` · `png` · `webp` 모두 됩니다
- 번호가 중간에 비어도 됩니다 (1, 2, 5번만 있어도 3장 나옵니다)
- 순서를 바꾸려면 파일 이름의 숫자만 바꾸세요

## 올리는 법 (GitHub 웹에서)

1. 이 폴더 화면에서 **Add file → Upload files**
2. 사진을 끌어다 놓기
3. 아래 **Commit changes** 클릭

1~2분 뒤 홈페이지에 자동 반영됩니다.

## 권장

- 가로 **1600px 이상**, 한 장당 **1MB 이하**
- 가로가 긴 사진이 잘 맞습니다
