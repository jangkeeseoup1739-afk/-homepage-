# 검색 노출 설정 (네이버 · 구글)

홈페이지를 만들어 두어도 검색엔진에 **등록**하지 않으면 네이버·구글 검색 결과에
나오지 않습니다. 아래 순서대로 한 번만 등록하면 됩니다.

> **중요 — 누구 계정으로 등록할지**
> 사이트 소유확인은 **등록한 계정에 권한이 묶입니다.** 제작자 계정으로 등록하면
> 나중에 의뢰인이 검색 노출 현황을 보거나 설정을 바꿀 수 없습니다.
> **의뢰인(살롱) 계정으로 등록**하는 것을 권합니다.

---

## 이미 되어 있는 것

아래는 코드에 반영되어 배포까지 끝난 상태입니다. 따로 하실 일이 없습니다.

| 항목 | 내용 |
| --- | --- |
| `robots.txt` | 모든 검색엔진 수집 허용 + 사이트맵 위치 안내 |
| `sitemap.xml` | 페이지 목록 (현재 1개) |
| `canonical` | 대표 주소 지정 (중복 색인 방지) |
| Open Graph | 카카오톡·네이버·페이스북 공유 시 제목·설명·썸네일 |
| 공유 썸네일 | `og-image.jpg` (1200×630, 매장 전경) |
| 구조화 데이터 | `HairSalon` 스키마 — 상호, 주소, 전화, 영업시간 |

## 1단계 — 네이버 사이트 등록 (필수)

1. [네이버 서치어드바이저](https://searchadvisor.naver.com) 에 접속해 로그인합니다.
   **살롱 네이버 계정으로 로그인하세요.**
2. 오른쪽 위 **웹마스터 도구** → **사이트 등록** 을 누릅니다.
3. 주소 입력칸에 아래를 넣고 등록합니다.

   ```
   https://isumok-hair-story.vercel.app/
   ```

4. **사이트 소유확인** 화면이 나옵니다. **HTML 태그** 방식을 고르면
   이런 줄이 나옵니다.

   ```html
   <meta name="naver-site-verification" content="a1b2c3d4e5f6...." />
   ```

5. **이 `content` 안의 값을 복사해서 전달해 주세요.** 코드에 넣고 재배포하겠습니다.
   (직접 하시려면 `index.html` 의 주석 처리된 `naver-site-verification` 줄을
   살리고 값을 채우면 됩니다.)
6. 배포가 끝난 뒤 서치어드바이저로 돌아와 **소유확인** 버튼을 누릅니다.

### 소유확인이 끝나면 이어서

- **요청 → 사이트맵 제출** 에 `sitemap.xml` 을 넣습니다.
- **요청 → 웹페이지 수집** 에 `https://isumok-hair-story.vercel.app/` 을 넣습니다.
  (수집 요청을 해야 빨리 올라옵니다. 보통 며칠 걸립니다.)

---

## 2단계 — 구글 사이트 등록 (선택)

1. [구글 서치 콘솔](https://search.google.com/search-console) 접속 → **URL 접두어** 에
   `https://isumok-hair-story.vercel.app/` 입력
2. 소유확인 방법에서 **HTML 태그** 를 고르면 네이버와 같은 형태의 코드가 나옵니다.
   그 값도 전달해 주시면 함께 넣겠습니다.
3. 확인 후 **Sitemaps** 메뉴에 `sitemap.xml` 제출

---

## 주소(도메인)를 바꾸게 되면

`isumok-hair-story.vercel.app` 대신 별도 도메인을 연결하면 아래를 **전부** 새 주소로
고쳐야 합니다. 하나라도 빠지면 검색 노출이 깨집니다.

- `index.html` — `canonical`, `og:url`, `og:image`, `twitter:image`, 구조화 데이터의 `url`·`image`
- `public/robots.txt` — `Sitemap:` 줄
- `public/sitemap.xml` — `<loc>` 줄
- 네이버·구글에 **새 주소로 다시 사이트 등록 + 소유확인**

도메인이 정해지면 말씀해 주세요. 한 번에 정리해 드리겠습니다.

---

## 검색에 바로 안 나와도 정상입니다

등록 직후에는 검색해도 나오지 않습니다. 네이버는 보통 **수일~2주**, 구글은
**며칠** 걸립니다. 수집 요청을 해두면 더 빠릅니다.

그동안에도 **네이버 플레이스(지도) 노출은 홈페이지와 별개로 동작**합니다.
살롱을 찾는 손님 대부분은 네이버 지도·플레이스로 들어오므로, 그쪽 정보가
최신인지 함께 확인해 보시는 것이 좋습니다.
