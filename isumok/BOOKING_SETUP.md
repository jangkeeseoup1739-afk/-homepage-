# 예약 신청 자동 정리 설정

홈페이지에서 고객이 **1:1 예약 및 맞춤 상담 신청**을 작성하면,

- **구글 시트**에 한 줄씩 자동으로 쌓이고
- 접수 즉시 **이메일 알림**이 옵니다 (휴대폰 Gmail 앱에서 바로 확인 가능)

비용은 들지 않고, 별도 서버도 필요 없습니다. 아래 순서대로 한 번만 설정하면 됩니다.
전체 10~15분 정도 걸립니다.

> **설정 전까지는 예약 신청이 원장님께 전달되지 않습니다.**
> 그동안에는 고객이 신청 버튼을 누르면 "전송에 실패했습니다" 화면과 함께
> 전화번호 두 개가 표시되어, 전화로 예약할 수 있게 안내됩니다.

---

## 1단계 — 구글 시트 만들기

1. 크롬에서 주소창에 `sheets.new` 를 입력하고 엔터를 누릅니다. 빈 시트가 새로 만들어집니다.
2. 왼쪽 위 제목을 `이수목헤어스토리 예약신청` 으로 바꿔 둡니다. (나중에 찾기 쉽게)

## 2단계 — 스크립트 붙여넣기

1. 상단 메뉴에서 **확장 프로그램 → Apps Script** 를 누릅니다. 새 탭이 열립니다.
2. 화면에 이미 적혀 있는 코드(`function myFunction() { }`)를 **전부 지웁니다.**
3. 이 저장소의 [`google-apps-script/booking-webhook.gs`](google-apps-script/booking-webhook.gs) 파일 내용을
   **전부 복사해서 붙여넣습니다.**
4. **알림을 받을 주소를 넣습니다.** 붙여넣은 코드 위쪽에서 이 줄을 찾아

   ```js
   var NOTIFY_EMAIL = '';
   ```

   따옴표 안에 **원장님이 실제로 메일을 확인하시는 주소**를 넣습니다.
   구글 계정이 아니어도 됩니다. 네이버·다음 메일 주소를 그대로 쓰면 됩니다.

   ```js
   var NOTIFY_EMAIL = 'name@naver.com';
   ```

   여러 명이 받으려면 쉼표로 구분합니다: `'name@naver.com, shop@gmail.com'`

   > 비워 두면 이 스크립트를 만든 구글 계정 주소로 갑니다. 그 계정의 메일함을
   > 평소에 보지 않으신다면 예약 알림을 놓치게 되므로, 반드시 채워 넣으세요.

5. 디스크 모양 저장 아이콘(또는 `Ctrl+S`)을 눌러 저장합니다.

## 3단계 — 웹앱으로 배포하기

1. 오른쪽 위 파란색 **배포 → 새 배포** 를 누릅니다.
2. 왼쪽 톱니바퀴(유형 선택)를 눌러 **웹 앱** 을 고릅니다.
3. 아래와 같이 설정합니다. **세 번째 항목이 가장 중요합니다.**

   | 항목 | 설정값 |
   | --- | --- |
   | 설명 | 아무거나 (예: 예약 접수) |
   | 다음 사용자로 실행 | **나** |
   | 액세스 권한이 있는 사용자 | **모든 사용자** |

4. **배포** 를 누릅니다.
5. 권한 승인 창이 뜹니다. **액세스 승인 → 본인 구글 계정 선택** 순서로 진행합니다.
6. "Google에서 확인하지 않은 앱입니다" 라는 경고가 나오면 놀라지 마세요.
   본인이 방금 만든 스크립트라서 나오는 정상적인 화면입니다.
   **고급 → (제목) (으)로 이동 → 허용** 을 차례로 누릅니다.
7. 마지막에 나오는 **웹 앱 URL** 을 복사합니다. 이렇게 생긴 주소입니다:

   ```
   https://script.google.com/macros/s/AKfycb................/exec
   ```

   이 주소를 메모장이나 카톡 내게쓰기에 붙여넣어 두세요. 다음 단계에서 씁니다.

## 4단계 — 홈페이지에 주소 연결하기

두 가지 방법 중 편한 쪽을 고르시면 됩니다.

### 방법 A — Vercel 대시보드에 넣기 (코드를 건드리지 않음)

1. [vercel.com](https://vercel.com) 로그인 → `isumok-hair-story` 프로젝트를 누릅니다.
2. 위쪽 **Settings** 탭 → 왼쪽 메뉴 **Environment Variables** 를 누릅니다.
3. 아래처럼 입력하고 **Save** 를 누릅니다.

   | 칸 | 입력값 |
   | --- | --- |
   | Key (이름) | `VITE_BOOKING_ENDPOINT` |
   | Value (값) | 3단계에서 복사한 웹 앱 URL |
   | Environment | 전부 선택 (Production, Preview, Development) |

4. 위쪽 **Deployments** 탭으로 가서 맨 위 항목 오른쪽 **⋯ → Redeploy** 를 누릅니다.
   (환경 변수는 다시 배포해야 적용됩니다.)

### 방법 B — 코드 파일에 직접 넣기

`src/config.ts` 파일을 열어 아래 줄의 따옴표 안에 주소를 붙여넣고 저장·푸시합니다.

```ts
const FALLBACK_BOOKING_ENDPOINT = '';
```

직접 하기 어려우시면 주소만 알려주세요. 대신 넣어 드리겠습니다.

## 5단계 — 확인하기

1. 배포가 끝나면 홈페이지를 열어 예약 신청 폼을 **직접 한 번 작성해서 제출**해 보세요.
   (고객명에 `테스트`, 연락처에 본인 번호를 넣으면 됩니다.)
2. 1단계에서 만든 구글 시트에 `예약신청` 탭이 생기고, 방금 넣은 내용이 한 줄 들어왔는지 봅니다.
3. 2단계에서 넣은 주소로 `[이수목헤어스토리] 예약 신청 — 테스트 010-...` 제목의
   메일이 왔는지 봅니다. 발신자는 `이수목헤어스토리 홈페이지` 로 표시됩니다.

   > **네이버·다음 메일로 받는 경우 이 확인이 특히 중요합니다.**
   > 메일이 안 보이면 **스팸함**을 열어 보세요. 거기 있다면 그 메일을 열어
   > **「스팸 아님」** 을 반드시 눌러 주세요. 이 처리를 해두지 않으면 앞으로
   > 들어오는 예약 알림이 계속 스팸함으로 들어가 예약을 놓치게 됩니다.
   > 발신 주소를 주소록에 추가해 두면 더 확실합니다.

4. 휴대폰에서 메일 앱 **알림을 켜 두세요.** 예약이 들어온 걸 바로 아셔야 합니다.
5. 확인이 끝나면 시트의 테스트 줄은 지우셔도 됩니다.

## 시트에 쌓이는 항목

| 열 | 내용 |
| --- | --- |
| 접수시각 | 고객이 신청 버튼을 누른 시각 |
| 접수번호 | 중복 접수를 걸러내는 데 쓰는 고유 번호 |
| 고객명 / 연락처 | 고객이 입력한 값 (연락처는 앞자리 0 이 유지됩니다) |
| 희망 방문일 / 희망 시간 | 고객이 선택한 날짜와 시간대 |
| 희망 시술 | 열펌, 링거펌, 커트 등 선택한 메뉴 |
| 모발·두피 고민 | 체크한 항목들 (여러 개면 줄바꿈으로 구분) |
| 기타 문의사항 | 자유 입력 내용 |
| 개인정보 동의 | 동의 / 미동의 |
| 진행 상태 | 접수완료 (이후 시트에서 직접 고쳐 쓰셔도 됩니다) |

## 자주 생기는 문제

| 증상 | 원인과 해결 |
| --- | --- |
| 시트에 아무것도 안 쌓임 | 3단계에서 **액세스 권한이 있는 사용자**가 "모든 사용자"가 아닐 가능성이 큽니다. 배포 → 배포 관리에서 연필 아이콘을 눌러 수정하세요. |
| 이메일만 안 옴 | 스팸함을 확인해 보세요. Gmail 하루 발송 한도(무료 계정 100통)를 넘겼을 수도 있습니다. |
| 스크립트를 고친 뒤 반영이 안 됨 | 코드를 수정했으면 **배포 → 배포 관리 → 연필 → 버전: 새 버전 → 배포** 를 해야 반영됩니다. 이때 URL은 바뀌지 않습니다. |
| 주소를 바꿨더니 접수가 안 됨 | 새 배포를 만들면 URL이 바뀝니다. 4단계의 값을 새 주소로 다시 넣어 주세요. |
| 같은 신청이 두 줄로 쌓임 | 정상적으로는 접수번호로 걸러집니다. 계속 그러면 알려주세요. |

## 문자(SMS)로 받고 싶다면

휴대폰 문자로 직접 받으시려면 아래가 추가로 필요합니다. 이메일 알림과 달리 **무료가 아니고, 준비물이 있습니다.**

- **문자 발송 대행 서비스 가입** — 알리고, 솔라피(쿨SMS), NHN Cloud 등. 건당 대략 9~20원의 선불 충전 방식입니다.
- **발신번호 사전등록** — 전기통신사업법에 따라, 문자를 보낼 번호를 미리 등록해야 합니다.
  통신서비스 가입증명원 등 서류가 필요하고 승인까지 보통 1~3일 걸립니다.

즉 오늘 바로는 안 되고 며칠 준비가 필요합니다. 그래서 우선 **이메일 알림**으로 만들어 두었습니다.
휴대폰에 Gmail 앱을 설치하고 알림을 켜 두시면, 실제 체감은 문자와 거의 같습니다.
