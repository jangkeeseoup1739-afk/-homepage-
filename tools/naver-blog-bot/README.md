# 네이버 블로그 자동 발행

`posts` 폴더에 글을 넣어두면, 네이버 블로그에 자동으로 올려주는 프로그램입니다.

---

## ⚠️ 먼저 읽어주세요

**네이버 이용약관은 자동화 프로그램 사용을 금지합니다.** 적발되면 블로그가 저품질 처리되거나 계정이 정지될 수 있습니다. `blog.naver.com/ks506l` 은 본업 계정이므로, 잃었을 때의 손해를 감안하고 쓰셔야 합니다.

위험을 줄이는 방법:

- **하루 1~2편까지만.** 기본 설정이 1편입니다. 늘리지 마세요.
- **매일 같은 시각에 돌리지 마세요.** 기계처럼 규칙적인 게 가장 눈에 띕니다.
- **글은 서로 달라야 합니다.** 제목만 바꾼 비슷한 글을 반복하면 네이버가 저품질로 분류합니다.
- **가끔은 직접 쓰세요.** 댓글 답글, 이웃 활동도 섞이는 게 좋습니다.

---

## 처음 한 번만 하는 설정

### 1. Node.js 설치

https://nodejs.org 에서 **LTS** 버전을 내려받아 설치합니다. 설치 중 선택지는 전부 기본값으로 두시면 됩니다.

### 2. `1-처음설정.bat` 더블클릭

필요한 프로그램을 자동으로 내려받습니다. 3~5분 걸립니다. 검은 창이 뜨고 글자가 올라가는데, "완료" 가 뜰 때까지 닫지 마세요.

### 3. `2-로그인.bat` 더블클릭

브라우저가 열리면 **네이버에 직접 로그인**하세요. 2단계 인증이나 기기 등록이 나오면 끝까지 진행하시면 됩니다.

> 아이디와 비밀번호는 이 프로그램이 저장하지 않습니다. 로그인한 브라우저 상태만 `.naver-profile` 폴더에 보관됩니다. 이 폴더는 남에게 주지 마세요. 로그인 상태가 들어 있습니다.

로그인은 보통 몇 주간 유지됩니다. "로그인이 필요합니다" 오류가 나면 이 파일을 다시 실행하세요.

## 매번 하는 일

### 1. 글 준비

`posts` 폴더에 `.md` 파일을 넣습니다. 형식은 이렇습니다.

```
# 여기가 제목입니다
태그: 제이원플렉스, 주안국가산단역, 지식산업센터

첫 문단입니다.

둘째 문단입니다. 빈 줄로 나누면 문단이 나뉩니다.
```

- 첫 줄은 반드시 `# ` 으로 시작하는 제목
- `태그:` 줄은 없어도 됩니다
- 나머지가 본문입니다

예시 글 3개가 들어 있으니 형식을 참고하세요.

### 2. `3-글올리기.bat` 더블클릭

파일 이름 순서대로 올립니다. 올린 글은 `done` 폴더로 옮겨지고, `발행기록.csv` 에 기록이 남습니다.

브라우저가 눈에 보이게 열립니다. **발행 직전 5초 카운트다운**이 있어서, 그 사이에 창을 닫으면 발행이 취소됩니다.

---

## 설정 바꾸기

`config.json` 을 메모장으로 열어서 고칩니다.

| 항목 | 설명 |
| --- | --- |
| `blogId` | 블로그 주소의 아이디 부분 |
| `openness` | 전체공개 / 이웃공개 / 서로이웃공개 / 비공개 |
| `headless` | `true` 로 하면 브라우저가 안 보입니다. 익숙해지기 전엔 `false` 로 두세요 |
| `countdownSeconds` | 발행 직전 대기 시간(초) |
| `postsPerRun` | 한 번에 올릴 글 수. **1 또는 2를 권장** |
| `delayBetweenPostsMs` | 글 사이 대기 시간(밀리초). 180000 = 3분 |

## 예약 실행 (선택)

매일 정해진 시각에 자동으로 돌리려면 **Windows 작업 스케줄러**를 씁니다.

1. 시작 메뉴에서 "작업 스케줄러" 검색 → 실행
2. 오른쪽 **기본 작업 만들기**
3. 이름: `블로그 자동 발행`
4. 트리거: **매일**, 시각 지정
5. 동작: **프로그램 시작** → `3-글올리기.bat` 선택
6. 마침

> 매일 정확히 같은 시각은 피하는 게 좋습니다. 작업 속성에서 "무작위 지연 시간"을 30분~1시간으로 주면 자연스러워집니다.

## 오류가 났을 때

네이버 에디터는 화면 구조가 자주 바뀝니다. 그때마다 이 프로그램도 고쳐야 합니다.

오류가 나면 폴더에 **`오류화면-숫자.png`** 파일이 생깁니다. 검은 창에 뜬 메시지와 함께 이 그림을 보내주시면 어디가 바뀐 건지 찾을 수 있습니다.

**자주 나는 오류**

| 메시지 | 원인 | 해결 |
| --- | --- | --- |
| 로그인 정보가 없습니다 | 로그인 안 함 | `2-로그인.bat` 실행 |
| 화면에서 요소를 찾지 못했습니다 | 네이버 화면 구조 변경 | 오류 화면 그림과 함께 문의 |
| Node.js 가 설치되어 있지 않습니다 | Node 미설치 | nodejs.org 에서 LTS 설치 |
