# 내부 사진 넣는 곳

**이 폴더에 사진 파일을 넣기만 하면 홈페이지에 자동으로 나타납니다.**
HTML 코드는 건드리지 않으셔도 됩니다.

## 파일 이름

숫자로만 지어 주세요. 홈페이지에 나오는 순서가 곧 번호 순서입니다.

```
1.jpg
2.jpg
3.jpg
...
```

- 최대 **24장**까지 들어갑니다 (`1` ~ `24`)
- 확장자는 `jpg` · `jpeg` · `png` · `webp` 모두 됩니다
- 번호가 중간에 비어도 괜찮습니다 (1, 2, 5번만 있어도 그 3장이 나옵니다)
- 순서를 바꾸고 싶으면 파일 이름의 숫자만 바꾸면 됩니다

## 권장 사항

- 가로가 긴 사진이 잘 맞습니다 (4:3 비율로 보입니다)
- 가로 **1600px 이상**이면 큰 화면에서도 깨지지 않습니다
- 한 장당 **1MB 이하**로 줄이면 휴대폰에서 빠르게 열립니다

## 사진이 없을 때

한 장도 없으면 홈페이지에서 **「내부 사진」 구역이 통째로 사라집니다.**
빈칸이나 "준비 중" 같은 문구가 손님께 보이지 않으니 그대로 두셔도 됩니다.

## 사진을 누르면

손님이 사진을 누르면 크게 확대되어 보입니다. 다시 누르면 닫힙니다.
